## 🌟 О проекте

**WinMosaic** — это полнофункциональная современная оболочка начального экрана Windows 8.1, написанная на C# и WPF (.NET 8). Она воссоздает легендарный интерфейс «Пуск» с максимальным вниманием к оригинальным деталям, плавности анимаций, звукам и возможностям кастомизации.

### ✨ Ключевые возможности:
- 🚀 **Полноэкранный «Пуск»**: Открытие по клавише `Win` или клику на кнопку Пуск панели задач на любом мониторе.
- 📐 **Живые плитки (Live Tiles)**: Плитки разных размеров (Small, Medium, Wide, Large) с 3D-анимациями переворота (Flip animation), динамическими часами, погодой, новостями, финансовыми котировками и фото.
- 🎨 **Персонализация**: Выбор оригинальных узоров и цветовых схем Windows 8.1 в реальном времени.
- 🛠 **Редактор Studio**: Добавление своих плиток, выбор иконок из каталога Metro Icons (500+ аутентичных иконок), настройка путей и параметров запуска.
- 🖥 **Поддержка нескольких мониторов**: Выбор конкретного монитора или динамическое отображение на том экране, где был сделан клик.
- 🌐 **Мультиязычность**: Полная поддержка русского и английского языков (RU / EN).
- ⏻ **Автозагрузка**: Включение/выключение автозапуска с Windows прямо из меню «Параметры» (Settings Charm) или трея.
- 👑 **Основатели (Credits)**: Специальная вкладка с информацией об авторах проекта.

## 📦 Установка и запуск

### Требования:
- Windows 10 или Windows 11 (x64)
- [.NET 8.0 SDK / Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

### Быстрый старт:
Запустите `install.bat` от имени обычного пользователя. Скрипт соберет проект в конфигурации Release, скопирует файлы в `%LOCALAPPDATA%\Programs\WinMosaic` и зарегистрирует автозапуск.

Для ручной сборки:
```bash
dotnet build -c Release
dotnet publish -c Release -o "%LOCALAPPDATA%\Programs\WinMosaic"
```
